# Bank Account Management System

## Description
A banking application to manage customer accounts and transactions.

## Features
- Create Account
- Deposit Money
- Withdraw Money
- Display Accounts
- Transaction History
- Delete Account
- Save Records

## OOP Concepts Used
- Classes & Objects
- Encapsulation
- Inheritance
- Abstraction
- File Handling
- Exception Handling

## Technologies
- Python 3
- CSV
