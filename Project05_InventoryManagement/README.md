# Inventory Management System

## Description
A console-based inventory management application for products.

## Features
- Add Product
- Display Products
- Search Product
- Update Product
- Delete Product
- Inventory Report
- Save Records

## OOP Concepts Used
- Classes & Objects
- Encapsulation
- Inheritance
- Abstraction
- File Handling
- Exception Handling

## Technologies
- Python 3
- CSV
