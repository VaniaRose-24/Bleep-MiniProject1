# Expense Tracker

## Description
A console-based application to record and manage income and expenses.

## Features
- Add Record
- Display Records
- Search Record
- Update Record
- Delete Record
- Monthly Summary
- Save Records

## OOP Concepts Used
- Classes & Objects
- Encapsulation
- Inheritance
- Abstraction
- File Handling
- Exception Handling

## Technologies
- Python 3
- CSV
