# Vehicle Rental Management System

## Description
A vehicle rental application to manage rentals and returns.

## Features
- Add Vehicle
- Display Vehicles
- Search Vehicle
- Rent Vehicle
- Return Vehicle
- Calculate Rental Charges
- Save Records

## OOP Concepts Used
- Classes & Objects
- Encapsulation
- Inheritance
- Abstraction
- File Handling
- Exception Handling

## Technologies
- Python 3
- CSV
