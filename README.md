# Python OOP Mini Projects Collection

This repository contains **10 console-based Python mini projects** developed as part of an Object-Oriented Programming (OOP) assignment. Each project demonstrates the practical use of OOP principles, file handling, exception handling, and modular programming.

---

## Projects Included

| Project | Description |
|---------|-------------|
| Project01 – Student Management System | Manage student records, marks, and grades. |
| Project02 – Library Management System | Add, search, issue, return, and manage books. |
| Project03 – Bank Account Management System | Create accounts, deposit, withdraw, and track transactions. |
| Project04 – Employee Payroll System | Manage employees and generate payroll details. |
| Project05 – Inventory Management System | Manage products and generate inventory reports. |
| Project06 – Quiz Management System | Load questions, conduct quizzes, calculate scores, and save results. |
| Project07 – Hospital Patient Record System | Register, search, update, and manage patient records. |
| Project08 – Vehicle Rental Management System | Manage vehicle rentals, returns, and rental charges. |
| Project09 – Expense Tracker | Record income and expenses with monthly summaries. |
| Project10 – Course Registration System | Register students for courses and manage enrollments. |
